# Dueña o dueño · hoja rápida

**En el sistema eres Propietario.** Ves todo y defines precios y seguridad.

## Poner en marcha

| Quiero… | Hago… |
|---|---|
| Saber qué falta | Inicio › «Primeros pasos» › botón de cada paso |
| Poner mis precios | Configuración › «Prestaciones» › «Editar» › «Precio (Bs)» › «Guardar» |
| Revisar consentimientos | Configuración › «Consentimientos» › «Nueva versión» (tras revisarlos con tu asesoría) |
| Exigir dos pasos al equipo | Configuración › «Seguridad» › «Marcar recomendados» › «Guardar política» |
| Activar mis dos pasos | Mi cuenta › «Activar» › contraseña › escanear › código › «Confirmar y activar» |
| Traer datos del sistema anterior | Importar datos › «Pacientes», «Citas futuras», «Saldos iniciales» › «Revisar» › «Importar» |
