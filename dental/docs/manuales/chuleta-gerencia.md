# Gerencia · hoja rápida

**En el sistema eres Administrador.** Ves todas las sucursales (selector arriba).

## Tareas frecuentes

| Quiero… | Hago… |
|---|---|
| Ver el mes | Inicio › números por sucursal · «Rango libre» · «Exportar a Excel» |
| Anular un pago | Caja › «Fecha» › «Movimientos del día» › «Anular» › motivo › «Anular pago» |
| Anular un cargo | Ficha › «Cuenta y pagos» › «Cargos» › «Anular» › motivo |
| Verificar pagos | Caja › «Pagos por verificar en el banco» › «Confirmar» o «Rechazar» |
| Revisar cierres de caja | Caja › «Cierres de caja» › N° › «Marcar revisada» |
| Cerrar honorarios | Honorarios › «Preparar borradores del período» › profesional › «Cerrar liquidación» › «Cerrar por Bs …» |
| Agregar personal | Configuración › «Personal» › «Agregar persona» › rol y sucursales › «Guardar» › entregar contraseña › «Ya la entregué» |
| Contraseña olvidada | Configuración › «Personal» › «Restablecer contraseña» |
| Horario de un profesional | Configuración › «Horarios» › «Profesional» › «Agregar turno» › «Guardar horario» |
| Asistencia | Gestión › «Fichaje» › «Agregar marca» › motivo › «Guardar corrección» |
| Rentabilidad | Gestión › «Rentabilidad» |
| Mensajes a pacientes | Menú › «Mensajes» |
| Quién hizo qué | Menú › «Actividad» |

## Reglas

- Nada se borra: se anula con motivo y queda registrado.
- Solo se anulan pagos **confirmados**; un pago «Por verificar» se rechaza.
- La contraseña temporal se muestra una vez: entrégala en persona, nunca por un grupo de WhatsApp.
- Una liquidación cerrada no cambia.
