# Modelo empresarial maestro: kit purificador de agua con filtro cerámico

Proyecto académico (Ingeniería Comercial / Juego de Negocios). Fusiona la metodología de los archivos Ñapefit e Hypotolab y la aplica a un producto físico no alimenticio. **No tiene relación con la tienda** del repositorio.

| Archivo | Contenido |
|---|---|
| `MODELO_EMPRESARIAL_MAESTRO.xlsx` | Libro integrado de 41 hojas y 8.592 fórmulas, en Bs |
| `AUDITORIA_COMPARATIVA.md` | Qué tenía cada original, errores corregidos, qué se conservó y qué no |
| `INFORME_DE_VIABILIDAD.md` | Producto, mercado, inversión, costos, rentabilidad, riesgos y recomendaciones |
| `GUIA_PARA_DEFENSA.md` | Explicación de cada hoja, método e indicador, con preguntas probables |
| `INFORME_DE_PRUEBAS.md` | Pruebas realizadas, resultados y limitaciones |
| `generador/` | Scripts que construyen y prueban el Excel |

Para usar el Excel, empezá por las hojas `INDICE` y `LEYENDA`. Las celdas azules con fondo amarillo son las únicas que se editan.
